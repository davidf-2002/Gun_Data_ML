# Gun_Data_ML

This project involves analyzing a dataset of gun violence incidents in the United States from January 2013 to March 2018. The primary goal is to preprocess the data, perform exploratory data analysis, and apply machine learning models to predict the severity of gun violence incidents based on various factors. I have chosen to implement XGBoost algorithm for my machine learning model.

## Link to dataset
https://github.com/jamesqo/gun-violence-data

## Prerequisites

Before running make sure the following packages are installed:
- dplyr
-  lubridate
-  tidyr
-  caret
-  xgboost

## Installation
Clone the repository:
```
git clone <url>
```

Navigate to the project directory:
```
cd Gun_Data_ML
```

Install the required packages:
```
pip install -r <requirements>
```
